# paper-analyzer 论文分析技能 — v1.5.0

用于理解、评议和比较已有学术论文。支持 PDF、Markdown、论文链接及粘贴的正文或摘要，输出语言默认跟随用户，读取能力取决于所用客户端提供的工具。

## 使用方式

只有三个主模式：**阅读、审稿、对比**。阅读分为**速读、详解、精读**三类；一次按请求选用其中一类。

| 主模式 | 阅读类型 | 请求示例 | 默认行为 |
| --- | --- | --- | --- |
| 阅读 | 速读 | “速读这篇论文” | 简要解释问题、方法和结果；中文通常 500–800 字，用户指定的篇幅优先 |
| 阅读 | 详解 | “按章节详解这篇论文” | 忠实跟随原文章节，解释公式、可见图表和相关附录 |
| 阅读 | 精读 | “精读这篇论文，准备组会” | 分析方法、证据、贡献和复现条件，按需配图与汇报建议 |
| 审稿 | — | “以审稿人视角评审” | 摘要、优势、不足、声明与证据映射、复现条件、作者问题 |
| 对比 | — | “对比这四篇论文” | 覆盖所有论文，先检查可比性，再给有条件的结论 |

未指定阅读类型的论文分析请求默认采用精读，输出一份连贯分析。“只解释公式里的温度参数”等局部追问直接作答，不重写完整模板。详解侧重忠实解释原文，精读侧重方法和证据分析，两者不只是篇幅不同。

“只要五条要点”“不画图”“不评分”等用户要求优先于默认模板。图表服务于解释，不是每篇论文的固定配额。只有摘要或部分材料时，也可以继续有限分析，并明确覆盖范围。

## 质量约定

- **证据可追溯**：关键数字与批评关联章节、表格、图或证明；区分作者报告、外部核实和分析者推断。
- **未知不等于缺失**：未提供代码链接不等于未开源；未检查附录不等于作者没有提供细节。
- **按论文类型评估**：覆盖实证机器学习、理论、综述、数据集/基准、系统/算法及定性/观察研究。无关维度标为 N/A，不因缺少训练、权重或消融给理论论文扣分。
- **复现条件与证据力度分开**：材料易于复现，不代表充分支持所有声明；未实际运行时，不声称复现成功或失败。
- **比较保留条件**：不同指标、测试划分、模型或预算的数字不能直接排名；复杂度也不等于实测速度。
- **尊重材料边界**：原文优先于译文；缺失图像、损坏公式和截断正文需要明确标记。

本技能支持论文讲解和汇报内容准备；不是新论文写作、纯全文翻译、通用幻灯片设计或 PDF 转换工具。需要这些交付物时，由宿主使用相应能力处理。

## 文件结构

```text
paper-analyzer/
├── SKILL.md                         # 三模式入口、共享输出规则、按需加载
└── references/
    ├── evidence-handling.md         # 来源、覆盖范围、未知信息与数值溯源
    ├── paper-types.md               # 不同论文类型的适用标准
    ├── modes/
    │   ├── reading.md              # 速读 / 详解 / 精读
    │   ├── review.md
    │   └── comparison.md
    ├── review-standards.md          # 审稿判断与证据力度
    ├── reproducibility-checklist.md # 复现/验证准备度
    └── mermaid-templates.md         # 按需选择的图表模板

```

分发或安装时使用整个 `paper-analyzer/` 文件夹，包括其参考文档；仓库根目录不是技能入口。将该文件夹放入所用客户端支持的 skills 目录，具体位置以客户端配置为准。

## 维护与验证

修改入口时保持有效 YAML frontmatter，维护引用路径。主模式、阅读类型和图表策略统一定义在 `SKILL.md`，模板只解释如何输出；阅读仅查阅 `reading.md` 中对应类型的段落。

本轮三模式重构通过技能入口、引用路径和十个合成论文场景的回归检查。合成场景不能替代真实 PDF/OCR、网页获取或 Mermaid 渲染的集成验证。本技能本身不依赖 Python 包或额外可执行脚本。

本地测试材料和验证记录存放在 `tests/`，由 `.gitignore` 排除，不随仓库提交。
