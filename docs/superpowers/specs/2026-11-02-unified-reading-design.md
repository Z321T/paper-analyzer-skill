# 统一阅读设计

用户已在对话中确认：默认定位为把论文讲透的研究伙伴；保留阅读、审稿、对比，取消速读、详解、精读三个固定子模式。

## 目标与约束

- 根据交付物选择模式，审稿视角不自动触发正式审稿结构。
- 阅读默认沿问题、前序工作、核心直觉、方法、证据和边界连贯展开；深度与顺序服从用户要求。
- 逐章要求保留源编号与覆盖义务；局部问题直接回答。
- 增强贯穿示例、公式解释、读者基础适配，优先处理关键理解障碍。
- 图表按解释目的选择，区分原文、数学推导、教学示意和实际运行；不绑定特定宿主。
- 背景检索有范围，区分历史与当前进展；复现表按需展开。
- 保留证据边界，集中重复定义；公开合成测试材料与实际验证记录。
- 不增加技能运行时依赖，不自动部署或发布。

## 考虑过的方案

1. 保留三个子模式：变化小，但深度与顺序仍混杂。
2. 合并详解与精读：简单，但仍容易把篇幅等同深度。
3. 统一阅读，按请求调整深度与顺序：用户选择此方案。

## 修改范围

更新入口、阅读模板、其他参考文档中的旧类型指引与 README；新增讲解、可视化指导及可公开测试。保留独立审稿、对比标准。机制理解与证据准确性优先于标题齐全。
